## Recommended build: two clearly separated feeds, one private service

**Market Value Feed (source-licensed):** a dedicated credential-holding private service/poller outside Delta. It must:
1. Query only a source whose explicit public API terms/permissions cover the intended automated personal-project use, and only through sanctioned documented endpoints at compliant rate; obtain free API key through the user's own login when required. Do not contact an individual if user doesn't want to.
2. Record `provider`, `sourceTermsVersion`, `sourcePublicationAt`, `providerRetrievedAt`, `perItemLastUpdated`, `providerKey`, `gameRawKeyVerified?`, `baseOrChroma`, `year`, `type`, `value`, `demand`, `stability`, `sourceA/B`, `upstreamDerivation`, `coverage`, `licenseStatus`, `digest`, `expiresAt`, `confidence`, `researchOnly`. **Never substitute retrieval clock for publisher update clock.** If the source is licensed only for internal consumption, don't publish raw full dataset through static GitHub or public APIs.
3. Maintain a private cache with independent source review and fail-closed validation: 401/403/429, exhausted rate limit, malformed/partial pages, missing or duplicate slugs, confusing Chroma variants, nonfinite prices, 50% sudden changed values, stale individual items, license changes, mapping collision, no external permission. No mapping by nearest/fuzzy alias into trade-authorized raw game keys.
4. Publish **only the minimal authorized versioned output** to the consumer, with authenticated integrity/rollback protections; never expose API key in Delta, public repo, logs or loader. A private backend can compute a bounded **non-secret** proposal if permitted; no full sourced values redistribution without rights. Signed digest/version, limited TTL, exact item whitelist and human-review confidence; no "verified" booleans supplied by Delta itself.

**Self-Observed Market Pulse (separate, originally sourced):** after lawful/authorized P3/P4 test, record private anonymous counts of P3/P4 actual offers/declines and confirmed accept/reject *with attribution*. It may estimate seller-interest patterns or list availability, not absolute prices, real sell-through or profit. **Do not activate Discord training until after mandatory trading tests**; test ALT, ambiguous close and historical webhook reports remain excluded. Calibrate real settle-based price/liquidity only once independently authenticated completion proof exists and samples sufficient to address selection bias.

**Planner binding contract:** an offer candidate needs exact valid session/partner/revision, item variant and four physical slots, fresh permitted source and reviewed raw mapping; source disagreement and unknown real liquidity remain explicit. No source-validity / stale / rights uncertainty -> `MARKET_BLOCKED` for actual economic offers; P3 contact eligibility can still function without numeric prices. Never outgoing Gingerscope, no auto final Accept, no unapproved value loss.
