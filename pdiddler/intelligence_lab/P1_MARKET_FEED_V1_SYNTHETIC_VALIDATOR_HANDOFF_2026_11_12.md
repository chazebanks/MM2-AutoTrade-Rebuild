**Requested milestone:** build and test the first market-feed input validator without asking a publisher for permission, creating keys, making network requests, or modifying the trading bot. **Status: complete for offline research only; all live market/trade/Discord permissions remain false.** This follows [P1 no-contact feed feasibility](P1_NO_CONTACT_LIVE_MARKET_FEED_FEASIBILITY_2026_11_12.md).

## Code and actual contract

- `pdiddler/ci/p1_market_feed_v1.py`: pure standard-library Python; imports and reuses `pdiddler/ci/p1_source_rights_gate.py` candidate research permission screening **and** Stage121's original denied-authority contract `pdiddler/intelligence_lab/stage121_source_to_strategy_firewall.py::FALSE`. It deliberately does **NOT** miscall Stage121's three-Supreme-page archival assessor on RBLXValue or MM2 Index API payloads.
- `pdiddler/ci/test_p1_market_feed_v1.py`: original full-source Python `unittest` suite, 37? focused named cases including **500 deterministic corrupted combinations**. The CI job `gingerscope-p1-canonical-archive-research.yml` runs them as part of original source-rights tests, without network.
- Function: `validate_feed(envelope, observed_utc="YYYY-MM-DDTHH:MM:SSZ")`. Accepted envelope has seven *exact* fields: `schema=gingerscope-market-feed-v1`, `mode=SYNTHETIC_OFFLINE_ONLY | EXTERNAL_UNTRUSTED`, `httpStatus`, `provider`, `snapshot`, `coverage`, and `previous` (null or provenance-bound previous snapshot). All other fields, including `apiKey`, `maySendDiscordWebhook` and self-proclaimed `verified`, are rejected.
- **provider** exact fields: name, declaredRights, upstreamProvenance, timestampMeaning and identityEvidence. Feed validity classification uses the **existing frozen P1 rights screening**; even CC BY 4.0 declarations, fresh publisher stamps and exact-game-key *claims* cannot authenticate actual right to source data.
- **snapshot** exact fields: version, publishedAtUtc, retrievedAtUtc, expiresAtUtc, units, items. Each item needs `providerKey,gameRawKey,rarity,variant,year,value,publishedAtUtc`. Every field is schema-checked: Ancient/Godly, Base/Chroma, copy/variant collision, 2000–2100 optional year, positive finite numeric listed value, strictly UTC publisher clock; max 5,000 entries. The whole collection and each item have independent publication-age bounds. This **is not a game-server source of identity**.
- **coverage** receives caller-supplied expected raw keys and enforces each is present exactly once; caller-supplied expected list is not evidence of *real* game universe coverage.
- **previous** uses same provider and same value unit and a strictly earlier publisher stamp/version; comparison of each overlapping current value with previous candidate flags a relative **>50%** move for review (research heuristic, not an approved trading limit). No currency averaging, rollover/replay, mixed provider or mixed units.
- Explicit safe outcomes: `KEY_REQUIRED` (401), `LICENSE_BLOCKED` (403/unknown/restricted/derivative), `RATE_LIMITED` (429), `SOURCE_UNAVAILABLE` (other), `STALE` (old publisher despite newly retrieved cache, invalid timestamp meaning/expired), `MAPPING_UNVERIFIED`, `INCOMPLETE`, `REVIEW_REQUIRED`, `BLOCKED`, `LIVE_CANDIDATE_UNVERIFIED`, or `SYNTHETIC_READY_FOR_SHADOW`. The last is **ONLY** for data with synthetic test names and completely artificial values, and it never authorizes even a live shadow market quote. NO result ever says `READY_TO_TRADE` or returns item prices.
- Result includes only safe aggregate count and derived SHA256 of locally supplied payload. A computed digest is *not* a signed first-party receipt, origin auth, verifiable rights grant, or cryptographic data transport authority. Every status emits all permanent `DENIED` and Stage121 `FALSE` flags including `maySendDiscordWebhook=false`, `mayUseForStrategyLearning=false`, `mayFeedStage120AsVerifiedMarket=false`, `authorizesTrade=false`, `authorizesAccept=false`, `serverCompletionProven=false`, `tradeOutcome=UNKNOWN`. P4 growth planner sees no certified economic price.

## Focused regression matrix (actual Python)

- Positive synthetic research fixture; identical digest; same input class from untrusted external source stays unverified.
- No-key **401**, restricted **403**, rate-limited **429**, 500, malformed HTTP codes: all blocked before cache.
- Unlicensed aggregator mixed from Supreme, API-access-only, provenance unknown, restricted data source: blocked; false `verified` fields cannot override.
- October 12 publisher date despite November 12 retrieval: `STALE`; aggregator refresh or display dates not accepted as independent publisher revision; future, expired, bad UTC and reversed clocks blocked.
- Exact raw-key/Chroma collisions, provider key reused, missing expected game key, unpriced or stale *individual* items, invalid rarity/year/variant, overflow/NaN/bools/string/nonpositive prices: blocked.
- Previous market publication rollback/replay, duplicate previous keys, cross-source/cross-unit comparisons, >50% variation: blocked/review; legitimate small change remains synthetic research only.
- Injection of `apiKey`, webhook authorities and real `Gingerscope` label into synthetic fixtures: blocked without leaking input contents. 500 seeded adversarial mutations never grant authority.
- Inherited original P1 source-rights guard, historical transport, MM2 Index independent research audit, old two-client receipt feasibility and all baseline Actions continue running.
