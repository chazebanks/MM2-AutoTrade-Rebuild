3. For **offline only** demand/supply studies, test a single immutable FairStash CC BY listing-count CSV with license attribution, dataset capture timestamp, source date, per-day sample window, and anonymized counts. No player identities; distinguish absence vs observed zero. Do not establish trade acceptance likelihood without separate observations.

Until a current, sufficiently covered, properly licensed valuation data path is established **and** exact MM2 raw weapon IDs and trade settlement gates are independently cleared, retain `MARKET_BLOCKED`; no auto offer, Accept, profit webhook or learning label. ## Nov 12 first-party Supreme distribution channels follow-up

**New verified source discovery (same day).** Crucial distinction: another vendor's copy is not automatically an approved data interface, but Supreme's own official partnerships deserve first review.

1. [Supreme information page](https://supremevalues.com/info) and [Supreme official Discord-bot page](https://supremevalues.com/discord/bot/) verify its own user interfaces: the website's personal inventory calculator auto-updates its displayed inventory value and offers an item-list export; the official Discord bot displays values, inventory statistics and trading history, behind Supreme-server verification and SVP+ subscription. Current published prices are $3.99 desktop / $5.49 iOS monthly. **This is authorized human-facing functionality, not a third-party API grant, permission to dump all Supreme values, or automated bot-ingestion authorization.** Export is described as a list of *the user's items*, not a licensed entire market dataset.
2. [Supreme's own site navigation](https://supremevalues.com/discord/bot/) expressly calls Cosmic Values its **official trading partner** and links `https://mm2.cosmicvalues.gg/`. [Cosmic Values MM2 landing page](https://mm2.cosmicvalues.gg/) independently states that its **real-time values are provided by Supreme Values**, with human-facing [trade calculator](https://mm2.cosmicvalues.gg/calculator). [Cosmic Values MM2 ToS](https://mm2.cosmicvalues.gg/terms-of-service) describes service features but contains **no discovered public developer API/data license or downstream redistribution grant to other bots**. The official partnership establishes rights between those two operators, not a transferable sublicense to Gingerscope. Avoid reverse-engineering private app endpoints, replaying user tokens, scraping its UI, or relabeling Cosmic as an independent valuation publisher.
3. [Supreme's current Terms](https://supremevalues.com/tos) define protected value-list fields to include numeric values, ranges, demand, rarity, stability, rising chance and flippability. They ban importing or manually transcribing values into an **application** or Discord bot for projects. They explicitly permit strictly personal use such as viewing the website, paper notes and using an arithmetic calculator. This does **not** give a blanket grant for unattended runtime software, even if only one person uses it.
4. **Recommended interim two-lane system:** (A) autonomous developer-testing/planning remains offline with independently permitted/non-Supreme estimates and complete fail-closed provenance; (B) for live decisions, present candidate items to the operator and link out to Supreme's own website or official partner's human-facing calculator for a *human one-off check and supervised decision*. Do not silently import checked Supreme values back as a full source feed. The direct Supreme-backed realtime autonomous mode must remain unavailable without published or specifically granted third-party feed permission.
5. **Best path for true unattended Supreme-backed implementation:** a separately documented **official supported integration / data-license** from Supreme (or Cosmic if it can demonstrate sublicensing rights for this third-party use). No such public self-service API/SDK license was verified in current research. User's existing no-provider-contact preference remains; no message, account creation, subscription or network data probe was sent. If no-contact persists, cannot honestly promise an automatic Supreme-synchronized bot.

**Decision:** `SUPREME_HUMAN_REFERENCE_AVAILABLE_AUTOMATED_FEED_NOT_GRANTED`. This is a viable product-design workaround for *manual supervised trading*, **not** a workaround for Supreme's API/ToS restrictions. No P3/P4, Delta, price importer, credentials or trade acceptance files changed.
