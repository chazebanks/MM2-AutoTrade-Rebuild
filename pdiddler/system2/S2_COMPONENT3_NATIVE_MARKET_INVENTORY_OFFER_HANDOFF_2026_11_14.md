## What actually exists

- `pdiddler/system2/native_market_inventory_offer_core.lua` is a pure native Luau evaluator that consumes the ORIGINAL `ScannerAPI.getOwnInventory()` output, validating all owned raw keys against game `Database.Sync` name, rarity, type, Chroma, quantity and stale-snapshot fingerprint. Uses ONLY the new 189-key market crosswalk prices; the scanner's hardcoded October 31 checker `value`, `total`, `checkerId`, `valueSource` **never** set current prices. Ensures every eligible raw-owned key appears in the scanner eligible list (no silently missing eligible inventory), and any newly eligible item outside mapped market remains unpriced/blocked.
- `pdiddler/system2/native_market_offer_client_capture.lua` is read-only P4-style original `TradeGUI/TradeGUI_Phone` capture from a specific already reviewed P3/P4 root, lease, JobId and exact player/partner UserIds. It reads at most four actual offer slots with stack labels, accepting the original Stage9 documented empty Amount text as one copy. Rejects a fifth visible physical slot, conflicting raw ID attributes, changed root/partner/lease or partial GUI. Captures twice and denies inconsistent frames. It does not start P3/P4 or send an action.
- `pdiddler/system2/native_market_inventory_offer_bridge.lua` joins these two components with the existing scanner API and immutable current public market snapshot. Its `newWithPinnedSource` uses an **immutable Git commit** `fd823dd0f0036c02ba4632a4f0a879bd429cb4fc` for `research_market_crosswalk_current.json`, and parses the retrieval timestamp as UTC. Snapshots expire after six hours, and own scanner observations after 30 seconds. Replacing the immutable pinned source requires a newly reviewed refresh; never restamp old quotes.
- Original `pdiddler/system2/native_offer_item_identity_resolver.lua` is reused for **one cautious read-only fallback**: if the real trade GUI does not expose a raw ID, a unique client game catalog name+Chroma/rarity candidate can be priced for *shadow observation only*, with `UNVERIFIED_NAME_ONLY_GAME_CATALOG_CANDIDATE`, `nameOnlyCatalogCandidateCount>0` and no action authority. Known Laser cross-tier ambiguity and other ambiguous catalog matches BLOCK. Never classify name-only candidate as exact raw ID/weapon instance.
- Each fresh offer read returns separate MM2 and Supreme listed value totals/deltas; missing publisher quotes stay `nil`, no invented zero. Its revision is explicitly a **client-only local GUI signature**, not an MM2 server trade revision. Changed offers/acceptance invalidate previous previews. Gingerscope outbound is always forbidden. All trade/offer/final Accept/profit/Discord/learning authority remains FALSE.
- Real public market row JSON is additionally archived as a short-lived Actions artifact and refreshed/published to the **research branch only** after all tests pass. Only PUBLIC source prices and original public raw-key candidate mapping are published; NO private owned inventory, partner name/userId, JobId or user receipt is published.
